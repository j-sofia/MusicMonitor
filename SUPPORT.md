# Support

MusicMonitor is a pre-release volunteer project. Before opening an issue:

1. Read [README.md](README.md) and [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
2. Search existing issues for the same Windows, monitor, or Spotify symptom.
3. Reproduce with the latest `main` branch when practical.

Use the bug-report form for reproducible defects and the feature-request form
for scoped ideas. Never attach OAuth callbacks, tokens, personal client IDs, or
Credential Manager exports. Security issues belong in the private reporting
flow described in [SECURITY.md](SECURITY.md).
